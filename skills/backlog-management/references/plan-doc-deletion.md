# Why a filed plan doc gets deleted

A plan file left beside the issues filed from it is a second copy of the same reasoning. When one copy changes and the other does not, the two drift, and a reader cannot tell which one is current. The issue is the record once it exists, so the plan file goes.

The rule is a required step in `SKILL.md` step 7. Left as a judgment call, plan files with every step closed accumulate in the plans folder.
